1. Query Summary

Eight information-retrieval queries are exposed from the Java console application under Main Menu → 5. Reports / queries. Each one is implemented as a PreparedStatement in QueryMenu.java.

#Business QuestionSQL Feature
1Which items belong to a given category?WHERE
2Where was each item found or lost, and who reported it?JOIN
3How many items has each reporter submitted?JOIN + COUNT + GROUP BY
4Which found items have never been claimed?Subquery
5How many claims has each validator verified versus rejected?JOIN + SUM + GROUP BY
6Which items have more than one claim request filed against them?GROUP BY + HAVING
7What are the five most recently found items?ORDER BY
8How long does it take, on average, from found to claim, per category?AVG + GROUP BY

3.2 Main menu

private static void runMainMenu(Connection conn, Console console) {
        boolean running = true;

        while (running) {
            System.out.println("\n===== FoundIt Lost and Found System =====");
            System.out.println("1. View records");
            System.out.println("2. Insert record");
            System.out.println("3. Update record");
            System.out.println("4. Delete record");
            System.out.println("5. Reports / queries");
            System.out.println("6. Exit");

            try {
                conn.setAutoCommit(true);

                switch (console.readChoice("Choose: ")) {
                    case 1 -> new ViewMenu(conn, console).run();
                    case 2 -> new InsertMenu(conn, console).run();
                    case 3 -> new UpdateMenu(conn, console).run();
                    case 4 -> new DeleteMenu(conn, console).run();
                    case 5 -> new QueryMenu(conn, console).run();
                    case 6 -> {
                        System.out.println("Goodbye!");
                        running = false;
                    }
                    default -> System.out.println("Invalid choice. Please enter 1-6.");
                }
            } catch (SQLException e) {
                System.out.println("Error: " + e.getMessage());
                Database.rollbackIfNeeded(conn);
            } catch (NumberFormatException e) {
                System.out.println("Invalid number. Please enter digits only.");
            } catch (IllegalArgumentException e) {
                System.out.println("Invalid date. Use the format yyyy-MM-dd HH:mm:ss");
            }
        }
    }

3.3 Query implementation

public void run() {
        while (true) {
            System.out.println("\n===== REPORTS / QUERIES =====");
            for (int i = 0; i < TITLES.length; i++) {
                System.out.printf("%d. %s%n", i + 1, TITLES[i]);
            }
            System.out.println("0. Back to main menu");

            int choice;
            try {
                choice = Integer.parseInt(console.readLine("Choose: "));
            } catch (NumberFormatException e) {
                System.out.println("Invalid input. Enter a number from 0 to " + TITLES.length + ".");
                continue;
            }

            if (choice == 0) {
                return;
            }
            if (choice < 1 || choice > TITLES.length) {
                System.out.println("Invalid choice. Enter a number from 0 to " + TITLES.length + ".");
                continue;
            }
            runQuery(choice - 1);
        }
    }

    private void runQuery(int idx) {
        try (PreparedStatement ps = conn.prepareStatement(SQL[idx])) {
            if (idx == 0) {
                String category = console.readLine("Category (e.g. Electronics, Clothing, Keys): ");
                if (category.isEmpty()) {
                    System.out.println("Category cannot be empty.");
                    return;
                }
                ps.setString(1, category);
            }

            try (ResultSet rs = ps.executeQuery()) {
                System.out.println("\n-- " + TITLES[idx] + " --");
                print(rs);
            }
        } catch (SQLException e) {
            System.out.println("Database error: " + e.getMessage());
        }
    }

    private void print(ResultSet rs) throws SQLException {
        ResultSetMetaData md = rs.getMetaData();
        int cols = md.getColumnCount();

        StringBuilder header = new StringBuilder();
        for (int c = 1; c <= cols; c++) {
            header.append(String.format("%-28s", md.getColumnLabel(c)));
        }
        System.out.println(header);
        System.out.println("-".repeat(header.length()));

        int rows = 0;
        while (rs.next()) {
            StringBuilder line = new StringBuilder();
            for (int c = 1; c <= cols; c++) {
                String value = rs.getString(c);
                line.append(String.format("%-28s", value == null ? "NULL" : value));
            }
            System.out.println(line);
            rows++;
        }
        if (rows == 0) {
            System.out.println("(no results)");
        }
    }

QueryMenu.java — run selects a query, runQuery binds the single parameter and executes it, print renders the ResultSet with aligned columns.

Error handling. All statements are prepared, so user input never reaches the SQL text. Database failures are caught and reported (Database error: <message>); multi-table writes roll back on failure (Changes were rolled back.); invalid menu input, non-numeric IDs, and malformed dates each print a specific message instead of terminating the program.

package com.mycompany.foundit;

public final class QueryMenu {

    private static final String[] TITLES = {
        "Items in a category (WHERE)",
        "Items with location and reporter (JOIN)",
        "Items reported per reporter (JOIN + COUNT + GROUP BY)",

        "Verified/unverified claims per validator (JOIN + SUM + GROUP BY)",
        "Items with more than one claim (GROUP BY + HAVING)",
        "Five most recently found items (ORDER BY)",
        "Average hours from found to claim, per category (AVG + GROUP BY)"

    private static final String[] SQL = {
        "SELECT item_id, item_name, item_category, item_type FROM Item WHERE item_category = ?",

        "SELECT i.item_id, i.item_name, i.item_type, l.location_name, "
      + "CONCAT(u.first_name,' ',u.last_name) AS reporter "
      + "FROM Item i JOIN Location l ON l.location_id = i.location_id "
      + "JOIN User u ON u.user_id = i.reporter_id ORDER BY i.item_id",

        "SELECT u.user_id, CONCAT(u.first_name,' ',u.last_name) AS reporter, COUNT(i.item_id) AS items_reported "
      + "FROM User u JOIN Item i ON i.reporter_id = u.user_id "
      + "GROUP BY u.user_id, u.first_name, u.last_name ORDER BY items_reported DESC",

        "SELECT i.item_id, i.item_name, f.found_at FROM Item i "
      + "JOIN FoundItem f ON f.item_id = i.item_id "
      + "WHERE i.item_id NOT IN (SELECT item_id FROM ClaimRequest)",

        "SELECT u.user_id, CONCAT(u.first_name,' ',u.last_name) AS validator, "
      + "SUM(c.request_type = 'VerifiedRequest') AS verified, "
      + "SUM(c.request_type = 'UnverifiedRequest') AS unverified "
      + "FROM ClaimRequest c JOIN User u ON u.user_id = c.validator_id "
